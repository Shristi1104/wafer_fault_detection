# Wafer Fault Detection Using Machine Learning

## Overview
This project focuses on detecting faulty semiconductor wafers using Machine Learning techniques. The goal is to automate the quality inspection process by analyzing wafer manufacturing data and predicting whether a wafer is faulty or non-faulty.

## Problem Statement
In semiconductor manufacturing, identifying defective wafers at an early stage is critical for reducing production costs and improving product quality. Manual inspection is time-consuming and prone to errors. This project leverages Machine Learning to accurately classify wafer faults.

## Features
- Data preprocessing and cleaning
- Handling missing values
- Exploratory Data Analysis (EDA)
- Feature selection and engineering
- Model training and evaluation
- Fault prediction for new wafer data
- Performance comparison of multiple ML algorithms
